# AuthlyX Go Example

This is a Go example project demonstrating how to integrate with the AuthlyX v2 API.

## Requirements

- Go (recommended: Go 1.21+)

## Quick Start

1. Open `main.go` and set your credentials.
2. Run:

```powershell
go run .
```

## What This Example Covers

- `Init()`
- Unified `Login(...)`:
  - username/password
  - license key
  - device (motherboard / processor)
- Variables (`GetVariable`, `SetVariable`)
- Chats (`GetChats`, `SendChat`)
- Extend time (`ExtendTime`)
- Change password (`ChangePassword`)
- Validate session (`ValidateSession`)
